# UI Session 2 — Shared UX, Money, login and Disco

## Audit and priorities

Session 1 was already present as uncommitted work and was preserved. This pass changes UI presentation only; no database, RLS, authentication, financial calculation or Insights redesign.

1. **Usability:** successful-save/timezone diagnostics occupied page-heading/card space in Planner, Rituals, Wellness, Money and Notes. Recovery handlers already existed and must remain accessible. A common painted indicator can reuse those owners rather than aggregate or fabricate synchronization.
2. **Money:** independent authored stacks intentionally differed in height, so Recorded Spending and Plan / Actual could not align. Recurring's summary combined a three-tile layout with a conflicting flex override in Overview. Past Paychecks lacked right alignment. Financial content used existing Geist sans but important supporting text was too small.
3. **Login:** existing shared split frame and actual invitation/magic-link behavior were correct. Copy differed from the newly approved text, and the live form linked to a development design preview.
4. **Disco:** the available repository history introduced the explicit `DiscoAtmosphere` mirrorball SVG, masked placement and measured header exclusions in commit `135c811`. No earlier full holographic version was found to restore verbatim. Current `.72` plum glass and shared restrained material layers muted the existing palette. This is direct implementation evidence, not evidence that Appearance consolidation caused a regression.
5. **Shared consistency:** standalone management actions reused underlined `text-button`, while real inline links/disclosures should retain their distinct roles. Existing title/date grids already align, so one shared top-padding addition suffices.

## Implemented

- `SaveIndicator` supplies scoped owner labels, status dots and loading/saving/unsaved/error/saved paint. Only loaded, clean, confirmed owners say All changes saved. Pending/saving precedes unsubmitted preferences. Existing error text, draft review, retry, conflict/discard and disabled behavior remain in their owning components. Daily/Planner/Wellness/Rituals/Money/Notes/Settings now use it; module success feedback lives in footers. Task Details retains only active loading/pending/draft/error feedback. No green status is inferred from browser connectivity.
- Shared page padding adds16px above both header tracks, reduced to8px on mobile. Horizontal gutters and sidebar are unchanged. Notes viewport measurement reserves its footer so the relocated status does not consume writing space through page overflow.
- Actual standalone Manage/Add/Cancel/View actions use the shared secondary/ghost hierarchy in the affected cards, Planner controls, Wellness libraries/forms, Money, Notes and recovery contexts. Inline links and native explanation disclosures remain. Session 1's interaction structure is preserved. Insights-specific actions remain for Session 3.
- Money Overview now has Current paycheck/Coming up, then the aligned Recorded spending/Plan / actual row, followed by full-width Recurring and Recent spending. Cards remain natural-height; no equalizing blank padding or fixed card heights. Recurring summaries use label / right-aligned tabular value / metadata tracks. Paychecks keeps compact Previous/Current/Next left and Past Paychecks right, aligned with Use Template. Readable financial totals and metadata use the existing font/tokens. Records/formulas are untouched.
- Approved **Wellness** heading/name replaces user-facing Nourish in the existing sidebar/mobile navigation, section labeling and source badge. Its approved Lucide `heart-pulse` geometry reuses `MuseIcon` and prismatic SVG treatments, with license attribution in `THIRD_PARTY_NOTICES.md`. Exact mantra: **Take care of yourself. You've got places to be.** Route `/nourish`, internal IDs, storage and all existing functions are unchanged.
- Login retains exact approved copy in the shared frame: Be the muse of your own life.; Life isn't one thing. Neither are you.; For the plans, the passions, the possibilities, and all the magic in between. The live card uses YOUR OWN LITTLE CORNER OF THE UNIVERSE, Welcome to Muse., and For everything you are and everything you're becoming. Its preview link is removed; invitation-only and magic-link behavior remains unchanged.
- Disco removes the literal SVG asset, header measurements/masks and mirrorball placement. It gains saturated prismatic atmospheric pools/caustics, chrome/foil glass paint, luminous control edges, official MuseStar glitter and a slow composited prism sweep. Quiet/Magical/Extra adjust decoration; Crystal/Frosted retain distinct optics; reduced motion stops twinkle/sweep. Paint is scoped to the existing Disco ID; other palettes are unchanged. Login participates in the same nonliteral light treatment.
